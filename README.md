# 🌿 Smart Agricultural Irrigation System - Mobile Application

## 📋 Project Overview
This project integrates IoT sensors with AI to create a **smart irrigation system** for agriculture, optimizing water usage and improving efficiency. The mobile app enables **real-time monitoring**, provides **AI-driven irrigation recommendations**, and offers **automated water distribution** to promote sustainable farming practices.

## 🚀 Key Features
- **IoT Integration**: Monitors soil moisture, temperature, and environmental conditions via sensors.
- **AI-Driven Analysis**: Machine learning algorithms predict and recommend optimal irrigation schedules.
- **Automated Irrigation**: Automatically controls water distribution based on real-time data.
- **Mobile Control**: Android application for remote monitoring and management.
- **Cloud Storage**: Stores data securely on Firebase for real-time access.
- **Historical Data**: View past irrigation records to make informed decisions.

## 🛠️ Technology Stack

### Mobile App
- **Language**: Java, XML
- **Framework**: Android Studio
- **Backend**: Firebase (User Authentication, Real-time Database)

### IoT Components
- **Microcontrollers**: Arduino, Raspberry Pi
- **Sensors**: DHT11 (temperature & humidity), soil moisture sensors
- **Actuators**: Water pump and relay system

### AI Integration
- **Language**: Python
- **Framework**: FastAPI (for API interactions)
- **Machine Learning**: Predictive algorithms to optimize irrigation schedules

## 📱 App Features
- **User Authentication**: Secure login and registration through Firebase.
- **Dashboard**: Real-time display of sensor data (soil moisture, temperature, etc.).
- **Control Panel**: Options for manual and automatic control of the irrigation system.
- **Notifications**: Alerts for critical events like low moisture levels.

## 🔧 Installation

### Prerequisites
- **Android Studio**: Ensure Android Studio is installed for mobile app development.
- **Firebase Setup**: Create a Firebase project for user authentication and database integration.
- **Arduino IDE**: Required for setting up sensors and actuators.
- **Python**: Ensure Python is installed to run AI models and the FastAPI backend.
